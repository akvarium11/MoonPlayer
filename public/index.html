About MoonPlayer
MoonPlayer
Version 2.5.0 + Riff M3 UI Engine
A modern, open-source audio player crafted with Tauri 2, Rust, and Web Audio API. Featuring 10-band equalization, SoundCloud streaming, Discord RPC, and switchable Material Design 3 interface.
